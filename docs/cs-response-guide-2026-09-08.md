# 교집합 카카오 비즈니스 CS 답변집

2026-09-08 작성 · 운영진 내부용 · 실제 상담을 바탕으로 한 1차 정리

## 읽는 방법

카카오 비즈니스의 상담 9개 채팅방과 도착 안내 1개 채팅방을 확인했다. 아래 근거표의 상담 기간은 8월 22일~9월 8일이다. 전체 채팅방을 전수 집계한 빈도 순위는 아니며, 같은 사람이 연속으로 보낸 메시지를 독립된 문의 건수로 세지 않았다. 일괄 발송 안내문도 고객 질문으로 세지 않았다.

**문하늘의 실제 답변을 중심으로 말투와 처리 방식을 정리했다.** 박동훈·이*현의 답변은 보조 근거로 별도 표시했다. 아래 답변은 원문 복사가 아닌 재사용 초안이다. 대괄호는 실제 기록으로 채우고, 처리 완료형 문장은 관리 화면에서 결과를 확인한 후에만 사용한다.

## 먼저 준비할 유형

2026-09-09 운영자 결정: **5번 신청·참여 확정 여부, 9번 참가자 나이대·조 구성은 자동답변에서 제외한다.** 해당 문의에는 운영진 확인이 필요하다는 안내만 제공하고 자동 상담을 중지한다. 아래 두 유형의 상세 내용은 운영진 참고용으로만 보존하며 AI 답변 지침으로 사용하지 않는다.

| 유형 | 관찰한 질문·상황 | 답변의 핵심 |
| --- | --- | --- |
| 1. 모임 신청 취소 | 참석이 어려워 취소 요청 | 어느 날짜인지 확인하고 신청 상태 변경 |
| 2. 결제 환불 | 취소하면 자동 환불인지, 환불 요청 | 모임 취소와 결제 환불을 구분 |
| 3. 다음 결제·구독 해지 | 해지 방법, 탈퇴하면 자동 해지인지 | 이번 환불·다음 자동결제·회원 탈퇴를 구분 |
| 4. 결제자 정보 불일치 | 프로필 이름과 주문자 이름이 다름 | 이름만으로 판단하지 않고 결제 기록 대조 |
| 5. 신청·참여 확정 상태 | 신청이 된 건지, 오늘 확정인지 | 결제·신청·배정의 실제 상태를 각각 확인 |
| 6. 장소와 공개 시간 | 오늘 일정·장소가 언제 나오는지 | 해당 모임의 공개 설정과 배정 장소 확인 |
| 7. 블라인드 데이트 날짜 변경 | 지정 날짜에 참석 불가 | 가능한 날짜를 받고 상대방과 조율 |
| 8. 데이트 취소·상대 신원 | 상대 사정으로 취소, 누구였는지 질문 | 취소 사실 안내, 상대 신원은 비공개 |
| 9. 참가자 나이대 | 어떤 나이대가 오는지 | 실제 구성 범위 안에서 답하고 확약하지 않기 |
| 10. 프로필 수정 | 이름 오타 수정 | 현재 화면의 수정 경로 안내 |

취소·환불·구독 관련 질문과 블라인드 데이트 일정 조정은 여러 채팅방에서 반복해서 확인됐다. 나머지는 이번 표본에서 확인된 개별 유형이다.

## 공통 말투와 첫 확인

문하늘의 답변은 짧은 인사와 이름 호칭으로 시작해, 확인한 상태와 다음 행동을 알려주는 방식이다. 취소 소식에는 기다린 점을 배려하는 사과가 붙고, 간단한 처리에는 “넵”, “확인 후”, “감사합니다 :)” 정도로 마무리한다.

- 첫 문의: “안녕하세요, [이름]님. …”
- 이미 대화 중: “넵 [이름]님, …”
- 정보 부족: 필요한 항목만 한 번에 요청한다. 이미 채팅방·기록으로 확인된 정보는 다시 묻지 않는다.
- 모호한 “취소” 요청: 일정 취소인지, 결제 환불까지 원하는지 확인한다.
- 완료 안내: 신청 취소 / 환불 / 구독 해지 중 **실제로 완료된 대상**을 적는다.
- 상대방 사유나 내부 평가를 불필요하게 설명하지 않는다.

신원 확인이 필요한 경우:

> 안녕하세요. 확인을 위해 성함과 휴대폰 번호 뒷 4자리, 신청하신 모임 날짜를 남겨주시면 확인해드리겠습니다.

근거: 문하늘의 S·김루비·유겸 상담. 뒷 4자리가 일치해도 동명이인·중복 주문이 있으면 추가 확인한다.

## 유형별 답변

### 1. 모임 신청 취소

**먼저 확인:** 대상 날짜, 신청 상태, 이미 배정되었는지, 환불도 원하는지. 배정된 참가자가 빠지면 조·상대방 운영에도 반영이 필요한지 확인한다.

접수:

> 넵 [이름]님, [날짜] 모임 취소 요청 확인했습니다. 신청 내역을 확인하고 처리해드리겠습니다.

“취소”의 범위가 모호할 때:

> [이름]님, 이번 모임 신청만 취소하시는 걸까요, 결제 환불도 함께 원하시는 걸까요?

신청 상태 변경 완료 후:

> 넵 [이름]님, [날짜] 모임 신청은 취소 처리되었습니다. 확인해주셔서 감사합니다.

**주의:** 신청 취소만 완료했는데 “환불되었습니다”라고 답하지 않는다. 근거: 김루비 상담, 이채원·설현 보조 사례.

### 2. 결제 환불

**먼저 확인:** 실제 결제 건, 금액, 환불 가능 여부와 처리 결과. 과거에 환불해준 사례만으로 모든 요청에 환불을 약속하지 않는다.

접수:

> 넵 [이름]님, 결제 내역과 환불 가능 여부를 확인한 뒤 안내드리겠습니다.

결제 시스템에 환불 완료가 확인된 뒤:

> [이름]님, 요청하신 [결제일 / 상품명] 결제 [금액]원은 환불 처리되었습니다.

다음 자동결제가 유지되는 것으로 확인된 경우에만 덧붙임:

> 다음 자동결제 해지는 별도로 필요합니다. 카카오톡으로 받으신 그로블 결제 알림의 ‘구매 내역 확인하기’를 확인해주세요.

**주의:** 결제 수단에 입금·승인 취소가 반영되는 날짜를 근거 없이 확약하지 않는다. 환불 완료와 신청 취소 반영을 각각 확인한다. 근거: S·김루비, 이채원 보조 사례.

### 3. 다음 결제·구독 해지·회원 탈퇴

실제 혼동: “환불했으니 구독도 끝났겠지”, “회원 탈퇴하면 자동결제도 멈추겠지”, “그로블의 어디에서 해지하지?”

> [이름]님, 이번 결제 환불과 다음 자동결제 해지는 별도로 확인이 필요합니다. 카카오톡으로 받으신 그로블 결제 알림의 ‘구매 내역 확인하기’를 확인해주세요. 해지 항목을 찾기 어려우시면 현재 보이는 화면을 보내주시면 안내드리겠습니다.

탈퇴 질문:

> [이름]님, 교집합 회원 탈퇴와 그로블 자동결제 해지는 별도입니다. 탈퇴만으로 자동결제가 중단되는 것은 아니니, 그로블에서도 구독 해지 상태를 확인해주세요.

**사용 조건:** 해당 고객이 그로블 구독 결제를 이용하는지 확인한다. 결제 알림의 버튼명은 2026-09-08 운영자 정정에 따라 ‘구매 내역 확인하기’로 안내한다. 그 이후 화면의 세부 해지 버튼은 확인 없이 추가하지 않는다. 근거: 문하늘의 S 상담, 박동훈의 후속 답변 및 이채원 상담, 운영자 정정.

### 4. 결제자 이름과 프로필 이름이 다를 때

> [이름]님, 신청 정보와 결제자 이름이 달라 추가 확인이 필요합니다. 결제하실 때 입력한 주문자명과 결제 당시 휴대폰 번호를 알려주시면 대조해드리겠습니다.

**처리 순서:** 신청자 확인 → 결제 당시 전화번호 대조 → 주문 일자·상품·금액 확인 → 중복·다른 사람 주문이 아닌지 확인 → 정확한 주문 처리 → 연결된 신청 상태 확인.

뒷 4자리만으로 주문이 특정되지 않으면 전체 번호 등 필요한 정보를 추가로 받는다. 다른 사람의 주문자명을 먼저 노출하기보다 고객이 입력한 정보를 받는 편이 좋다. 근거: 문하늘의 김루비 상담. 원래 답변은 발견한 주문자명이 맞는지 확인하는 방식이었다.

### 5. 신청이 된 건가요? 참여 확정인가요? — 자동답변 제외

신청은 접수됐지만 미배정인 경우:

> [이름]님, [날짜] 모임 신청은 접수되어 있고 현재 배정 대기 중입니다. 참여 확정 안내는 [실제 안내 예정 시점]에 확인하실 수 있어요.

배정까지 확정된 경우:

> 넵 [이름]님, [날짜] 모임 참여가 확정되어 있습니다. [시작 시간]에 시작하며, 장소는 [현재 공개 여부에 맞는 안내]에서 확인하실 수 있어요.

결제 확인이 안 된 경우:

> [이름]님, 현재 조회한 내역에서는 결제가 확인되지 않습니다. 이미 결제하셨다면 결제 일자와 주문자 정보를 남겨주시면 다시 대조해드리겠습니다.

**주의:** 결제 완료만으로 배정 완료라고 답하지 않는다. 과거 유겸 답변의 “미신청” 표현을 현재의 결제 대기·미배정 상태에 일괄 적용하지 않는다. 근거: 문하늘의 유겸·서지우 상담.

### 6. 장소는 언제 공개되나요?

공개 전:

> [이름]님, [날짜] 모임은 [지역]에서 진행됩니다. 정확한 장소는 [해당 모임의 공개 시점]에 안내드릴 예정입니다. 공개 후 웹사이트에서도 확인하실 수 있어요.

공개 후:

> [이름]님, 오늘 배정된 장소는 [장소명]입니다.
>
> [지도 링크]
>
> [시작 시간]에 시작하니 여유 있게 도착해주세요 :)

**주의:** 서지우 상담에는 “모임 시작 3시간 전”이라는 안내가 있었지만 실제 장소 메시지는 그보다 일찍 발송됐다. 공개 시점을 고정 문구로 저장하지 말고 해당 행사·해당 차수 설정을 확인한다. 근거: 문하늘의 서지우 상담.

### 7. 블라인드 데이트 날짜 변경

> 안녕하세요, [이름]님. 가능하신 날짜를 몇 가지 남겨주시면 상대방 일정 확인 후 조정해드리겠습니다.

아직 조율 중:

> [이름]님, 말씀해주신 [날짜]로 상대방 일정도 확인 중입니다. 두 분 일정이 맞는지 확인한 뒤 확정 안내드리겠습니다.

제안 날짜가 안 맞을 때:

> [이름]님, 말씀해주신 날짜는 상대방이 참석하기 어려운 것으로 확인됐습니다. 다른 가능한 날짜가 있으시면 남겨주세요.

더 이상 조율이 어렵고 취소가 확정됐을 때:

> [이름]님, 서로 가능한 일정이 맞지 않아 이번 블라인드 데이트는 진행이 어려워졌습니다. 기다려주셨을 텐데 아쉬운 소식을 전해드려 죄송합니다.

**주의:** 한쪽의 가능 답변만으로 변경 완료라고 말하지 않는다. 변경 확정 후 날짜·장소·양쪽 안내가 일치하는지 확인한다. 근거: 문하늘의 윤형식·서지우 상담.

### 8. 데이트 취소 안내와 상대방 신원 질문

취소 확정 안내:

> 안녕하세요, [이름]님. 예정되어 있던 [날짜] 블라인드 데이트가 상대방의 개인 사정으로 취소되어 안내드립니다. 기다려주셨을 텐데 아쉬운 소식을 전해드려 죄송합니다.

누구였는지 질문:

> [이름]님, 아쉽지만 상대방의 개인정보 보호를 위해 정확히 누구인지는 공개하지 않고 있습니다. 양해 부탁드립니다.

**주의:** 취소 사유를 추측하거나 상대방의 개인 사정을 구체적으로 전달하지 않는다. 기존 답변의 “선택하신 분 중 한 분”은 실제 상호 선택 기록이 확인될 때만 붙인다. 근거: 문하늘의 조시현 상담.

### 9. 참가자 나이대와 조 구성 — 자동답변 제외

> 안녕하세요, [이름]님. 이번 모임 신청자 나이대는 [확인한 범위]이며, 나이와 신청 내용을 함께 고려해 조를 구성하고 있습니다. 최종 구성은 신청 상황에 따라 달라질 수 있어요.

**주의:** 유겸 상담의 “20대 초반부터 후반”을 모든 행사 공통 기준으로 사용하지 않는다. 개별 참가자의 신상·외모 점수·선호 내용을 알려주거나 특정 구성·만남을 보장하지 않는다. 근거: 문하늘의 유겸 상담을 바탕으로 다듬은 제안 문구.

### 10. 이름·프로필 정보 수정

> 안녕하세요, [이름]님. 웹사이트 오른쪽 위 프로필 메뉴에서 정보를 수정하실 수 있어요. 수정 항목이 보이지 않으면 현재 화면을 보내주시면 확인해드리겠습니다.

**사용 조건:** 현재 사용자 화면에 해당 수정 경로가 있는지 먼저 확인한다. 이번 조사에서는 과거 답변만 확인했다. 근거: 김종민 상담의 **이*현** 답변. 문하늘의 직접 답변으로 분류하지 않는다.
