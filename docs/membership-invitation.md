# 특별 초대 1개월 멤버십

## 동작

- `/gift/<무작위 토큰>` 접속 시 서버에서 초대장을 확인하고 HttpOnly 쿠키에 30일간 보관함. 쿼리스트링으로 금액·기간·회원 ID를 받지 않음.
- 기존 첫 화면의 영상·문구·버튼을 재사용한 `/special-invitation`으로 이동함. 개발용 `/dev/special-invite-preview`는 실제 혜택을 지급하지 않음.
- 시작하기를 누르면 비회원은 기존 질문·회원가입, 가입을 마친 회원은 기존 서비스로 이동함. 기존 회원 로그인 경로도 유지함.
- 가입·프로필 완료 후 `/meetings`에 도착하면 로그인 세션의 계정에 자동 지급함. DB 오류 시 재시도 버튼을 제공하고 초대 쿠키를 보존함.
- 한 계정은 특별 초대 혜택을 한 번만 받을 수 있음. 다른 특별 초대 링크를 사용해도 중복 지급되지 않음.
- 현재 활성 멤버십은 기존 시작일·플랜을 유지하고 종료일 다음 날부터 1개월 추가함. 비활성·만료 멤버십은 한국 날짜 기준 당일부터 1개월을 시작함.
- 기간 계산은 기존 `calculateMembershipEndDate(one_month)`와 동일한 달력상 1개월임. 결제 기록이나 정기결제 구독을 생성하지 않음.
- 계정 행 잠금과 고유 지급 기록을 같은 DB 트랜잭션에서 처리함. 지급 실패 시 멤버십과 초대 사용 횟수가 함께 롤백됨.

## 배포와 초대 링크 발급

1. `20261103053456_membership_invitation_grants.sql` 마이그레이션을 먼저 적용함.
2. 애플리케이션을 배포함.
3. 올바른 환경의 `.env.local`을 사용하여 아래 명령을 실행함. 명령은 해당 DB에 초대장을 실제로 생성함.

```powershell
node --env-file=.env.local scripts/create-membership-invitation.mjs "특별 초대 1차"
# 선택: 만료일과 최대 지급 인원
node --env-file=.env.local scripts/create-membership-invitation.mjs "특별 초대 1차" "2026-12-31T14:59:59Z" 100
```

출력된 `/gift/...` 경로를 실제 서비스 도메인에 붙여 공유함. 링크를 아는 사람은 사용할 수 있는 공유 초대장임. DB에는 토큰 해시만 저장하므로 원본 링크는 출력 시 보관해야 함. 지정인을 대상으로 하는 1인 전용 초대장은 별도 기능임.

초대장 중단은 해당 `membership_invitations.id`의 `enabled`를 false로 변경함. 이후 지급을 차단하며 이미 지급된 멤버십은 회수하지 않음. 지급 내역은 `membership_invitation_grants`에서 초대 ID·계정·변경 전후 기간으로 확인함.

## 범위와 제한

- 동일 브라우저·도메인의 초대 쿠키로 가입을 이어감. 쿠키 삭제·다른 브라우저·다른 기기에서는 원래 초대 링크로 다시 접속해야 함.
- 중복 방지는 인증 계정 단위임. 여러 계정을 가진 동일인을 별도로 식별하는 기능은 추가하지 않음.
- 초대 유효기간·인원은 실제 지급 시에도 재확인함. 가입 도중 초대가 종료된 경우 지급하지 않음.
- 2026-11-03 운영 반영 요청에 따라 해당 마이그레이션을 적용하고 실제 공유 초대장을 발급함. 운영 계정에 시험 지급하지 않음.
