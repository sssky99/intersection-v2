# 행사 중심 운영

프로그램 메뉴와 선택 단계는 사용하지 않는다. 행사 관리에서 제목·날짜·시작 시간을 입력해 새 행사를 만들거나 기존 행사를 복제한다. 활동 이름·시간·장소는 행사 안의 일정에서 수정한다. 진행 상태 문구는 ‘배정 전 공통 화면 · 진행 안내’에서 수정한다.

## 사용자 화면

- 배정 전: meeting_events.detail_snapshot의 공통 여정을 보여준다.
- 배정 확정 후: 기존 티켓 인스턴스에 연결된 조의 장소·멤버·예약 정보를 기존 공개 규칙대로 반영한다.
- 행사별 공통 내용은 해당 행사 전용 ticket_templates에 동기화된다. 이 내부 연결은 관리자 입력이 필요 없다.

## 기존 데이터 이전

20260908121432_event_owned_content.sql은 행사마다 독립적인 내부 템플릿을 만들고 기존 조의 인스턴스와 참가 기록을 연결한다. 원래 공유 템플릿은 삭제하지 않는다. 신청 상태, 조 배정, 인스턴스 ID, 장소 및 공개 시점은 유지한다.

새 행사의 내용·행사·단계 생성은 한 DB 트랜잭션으로 처리한다. 기존 행사 복제는 공통 활동과 안내만 가져오며 신청자·장소·예약자명·공개 상태는 복사하지 않는다. 안내 수정은 JSON의 해당 키만 갱신하므로 동시에 수정된 여정을 덮어쓰지 않는다.

구형 티켓·샘플 도구는 ‘기존 티켓·샘플’에서 접근한다. 새 행사 운영에는 필요하지 않으며 프로그램 전용 화면과 API는 제거했다.
