# 프로그램과 행사 관리

- **프로그램 관리**: 제목, 소개, 기본 활동 2~3개, 기본 안내 및 진행 단계별 문구를 준비한다. 프로그램 전용 API는 신청자 정보를 조회하지 않는다.
- **행사 관리**: 저장된 프로그램을 선택한 뒤 날짜, 시작 시간, 모집·공개 설정, 조 및 장소를 관리한다. 프로그램의 활동 이름과 순서를 행사 생성 시 가져온다.
- **대기열 관리**: 신청자 확인과 수동 배정을 진행한다.

## 저장 범위

프로그램 저장은 항상 새 `ticket_templates` 행을 만든다. 원본과 연결된 행사·구형 티켓을 수정하거나 복제하지 않는다. 기존 티켓의 일부 화면이 원본 프로그램을 직접 참조하므로, 원본 덮어쓰기를 허용하지 않는다.

수정본 저장 후 선택된 새 프로그램으로 행사를 만든다. 같은 제목의 프로그램은 저장 시각으로 구별한다. 기존 프로그램은 기존 행사의 참조를 위해 유지한다. 프로그램 목록 자동 통합·삭제는 하지 않는다.

프로그램에는 날짜·시간·장소·예약자명을 복사하지 않는다. 활동 간 기본 간격으로 행사 초안을 만들고 실제 시각은 행사 관리에서 조정한다. 기존 추천 설정은 수정본에도 보존한다.

## 기존 도구

세부티켓·샘플·테스트 시간 도구는 프로그램 관리 상단의 **기존 티켓·샘플 도구**로 이동했다. 현재 호환 경로를 유지한 상태이며 삭제된 기능이 아니다. 캘린더의 기존 티켓 열기도 이 경로를 사용한다. 새 프로그램·행사는 이 구형 도구를 거치지 않는다.

이 변경은 스키마 마이그레이션이나 기존 운영 데이터 수정이 필요하지 않다.
