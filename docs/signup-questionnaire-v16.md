# 가입 질문 개편: preferences-v16

## 적용 범위

- 신규 가입자의 초기 질문을 합의한 20문항으로 변경함. 기본정보(생년월일·MBTI·이름·성별)는 성향·선호 질문 뒤에 배치함.
- 기존 preferences-v13/v14 가입자와 버전 정보가 없는 게스트 임시답변은 기존 질문으로 이어서 완료함. 기존 완료 계정을 일괄 변경하지 않음.
- 피드백 질문, 매칭 가중치, 로그인 전 질문 완료를 위한 새 수집 이벤트는 이번 변경에 포함하지 않음.

## 저장 번호

화면의 문항 순서와 `question_order`는 다름. 기존 답변 번호를 재배정하지 않음.

| 화면 순서 | 저장 번호 | 내용 |
|---|---|---|
| 1~9 | 6, 7, 8, 19, 25, 26, 27, 11, 12 | 기존 성향·환경 질문 |
| 10 | 37 | 취미·관심: 기존 취미 13번과 의미가 달라 별도 번호 사용 |
| 11~12 | 14, 28 | 관심사·일하는 분야 |
| 13 | 36 | 국가별 여행·거주 경험: 기존 자유 입력 30번 보존 |
| 14~17 | 32, 33, 34, 35 | 상대 대화 깊이·관계 속도 선호·대화 방식·공통점 중요도 |
| 18 | 18 | 선택 자유 입력 |
| 19~20 | 17, 31 | 생년월일·MBTI |

대화 깊이와 관계 속도 선호는 기존 질문과 같은 1~7 숫자 척도에서 하나만 선택함. `answer_value`에 문자열 `1`~`7`을 저장하며 선택 즉시 다음 질문으로 이동함. 범위 선택·무관·미정 선택지는 제공하지 않음. 국가 질문은 기존 30번과 같은 주관식 입력칸 하나를 사용하며, `answer_text`에 `일본, 프랑스, 태국`처럼 작성한 원문을 저장함. 나라별 추가나 여행·거주 분류는 받지 않음. 경험이 없다면 없다는 응답을 직접 작성할 수 있음. 국가명 표기 차이는 분석 단계에서 정규화가 필요함. 이전 미리보기의 구조화 국가 응답은 기존 표시용 변환 함수를 유지해 읽을 수 있음.

가입 질문 버전은 게스트 임시답변과 프로필에 보존함. 질문 시작·저장 완료의 기존 분석 이벤트에도 새 버전 정보를 첨부함. 로그인 전 질문 완료의 별도 서버 수집은 추가하지 않음.

## 배포 순서

1. `20261101090327_signup_matching_questions_v16.sql`을 적용해 새 프로필 버전 허용 및 기본값을 변경함.
2. 애플리케이션을 배포함. 마이그레이션보다 코드를 먼저 배포하면 신규 계정 생성이 제약 조건에 막힐 수 있음.
3. 새 가입·이전 임시답변 이어쓰기·선택 문항 건너뛰기·직접 입력·프로필 답변 표시를 확인함.

2026-11-01 운영 DB에 해당 마이그레이션만 적용하고 새 버전 허용·기본값을 확인함. 기존 사용자 행을 갱신하지 않음.
